# Korean Instagram ID Generator

한국인 느낌의 인스타그램 사용자명(ID) 후보를 대량으로 만들어 주는 **단일 HTML 파일 도구**입니다.
ID마다 이름(name)과 소개글(bio)도 함께 만들어 `username | name | bio` 표와 CSV로 내보냅니다.

> English: A single-file, no-build web tool that generates Korean-style Instagram username candidates
> (6–11 chars) with a matching display name and bio. Up to 20,000 per run, exportable as CSV.
> The UI is in English; names, nicknames and bios are Korean.

---

## 1. 빠른 시작

설치도 빌드도 서버도 필요 없습니다.

1. `index.html`을 내려받습니다.
2. 더블클릭해서 브라우저(Chrome, Edge 등)로 엽니다.
3. **Count**에 개수(기본 500, 최대 20,000)를 넣고 **Generate**를 누릅니다.
4. 결과를 확인하고 **Copy All** 또는 **Save CSV**로 가져갑니다.

헤더 부제에 `Up to 20,000 per run`이 보이면 최신 버전입니다. 이 문구가 없고 5,000개까지만 되면
이전 버전을 열고 계신 겁니다(→ [자주 묻는 질문](#6-자주-묻는-질문)).

## 2. 화면 설명

| 영역 | 설명 |
|---|---|
| **Count** | 한 번에 만들 개수. 1~20,000. 범위를 벗어나면 자동으로 맞춰집니다. |
| **Generate** | 생성 시작. 500개씩 나눠 처리하며 `Generating… N / M`로 진행률을 보여 줍니다. |
| **Stop** | 생성 중에만 나타납니다. 누르면 그때까지 만든 것만 저장하고 멈춥니다. |
| **Copy All** | 이번에 만든 전체를 탭(Tab)으로 구분해 클립보드에 복사합니다 (`username⇥name⇥bio`, 엑셀·구글시트에 바로 붙여넣기 가능). |
| **Save CSV** | **이번에 만든 것만** CSV로 저장합니다. |
| **Save All History** | 브라우저에 저장된 **누적 기록 전체**를 CSV로 저장합니다. |
| **Reset Storage** | 저장된 기록(중복 방지용)을 모두 지웁니다. |
| **Name gender** | `All` / `Female` / `Male`. 이름(성별이 있는 이름·닉네임)을 해당 성별로 제한합니다. 선택은 새로고침해도 유지됩니다. |
| 표 | `username`, `name`, `bio` 세 열. 헤더는 스크롤해도 고정됩니다. 긴 값은 마우스를 올리면 전체가 보입니다. 모바일에서는 bio가 줄바꿈되어 아래에 표시됩니다. |

화면에는 **앞 1,000개만** 표시합니다. 그 이상은 표 아래 안내 문구가 나오며, 전체는 Copy All / CSV로 받으세요.

## 3. 결과물 형식

### 표 / Copy All
`username`, `name`, `bio` 세 열입니다. bio는 비어 있을 수 있습니다(약 45%).

### CSV
- 컬럼: `username,name,bio,generated_at`
- 인코딩: UTF-8 + BOM (엑셀에서 한글이 깨지지 않도록)
- `generated_at`: `2026-10-12 13:12:40` 형식 (브라우저 로컬 시간)
- name, bio는 큰따옴표로 감싸고 내부 따옴표는 `""`로 이스케이프합니다.
- 파일명: `korean_ig_ids_batch_<개수>_<YYYYMMDD-HHMM>.csv` (Save All History는 `batch` 대신 `all`)
- 저장 위치: 브라우저 기본 다운로드 폴더 (Windows는 보통 `C:\Users\<사용자이름>\Downloads`)

예시:

```csv
username,name,bio,generated_at
diary._seo,"서준혁","부산 / 책 읽기 📷",2026-10-12 13:12:40
su_su9_808,"수진","",2026-10-12 13:12:40
```

## 4. 만들어지는 내용의 규칙

### username (ID)
- 길이 **6~11자**, 사용 문자는 소문자 `a-z`, 숫자 `0-9`, `.`, `_`
- `.`은 맨 앞/맨 뒤 불가, `..` 연속 불가
- 구분자(`.` `_`)는 최대 3개
- 너무 단순한 ID는 걸러냅니다 (구분자가 없고 숫자가 3자리 이하인 짧은 ID, 알파벳만으로 된 ID 등)
- 같은 브라우저에서 이미 만든 ID는 다시 나오지 않습니다 (기록은 localStorage에 저장)

### name (이름)
| 비율 | 형태 | 예 |
|---|---|---|
| 약 60% | 성+이름 | `서준혁` |
| 약 20% | 이름만 | `수진` |
| 약 10% | 한국 이름의 영문 표기 | `Seoyeon Kim`, `Kim Seoyeon`, `Seoyeon` |
| 약 10% | 랜덤 닉네임 | `햇살`, `금둥이` |

추가로 약 5%의 이름 끝에 이모지가 한 개 붙습니다 (`주호 🦋`).
ID 생성 방식 중 "닉네임 기반" 방식(전체의 약 5%)은 이름 칸에 닉네임이 그대로 들어갑니다.

### bio (소개글)
- 약 55%에 bio가 있고 나머지 45%는 비어 있습니다.
- bio가 있는 경우: 60%는 미리 만든 문구 50개 중 하나, 40%는 `[지역] / [내용] [이모지]` 조합입니다.
- 전체 행의 약 30%의 bio에 이모지가 들어갑니다 (이름 끝 이모지까지 합치면 약 35%, 2만 개 측정 기준).
- 한국어 위주이며 일부 영어 문구가 섞입니다.

### 성별 필터
- `Female` / `Male`을 고르면 여자(또는 남자) 이름과 **중성 이름**만 사용합니다.
- 닉네임, 이름 표기용 단어에도 성별 구분이 적용됩니다 (예: 남자 필터에서는 `공주`, 여자 필터에서는 `소년`이 나오지 않음).
- 성별 판단이 애매한 이름(지민, 수현, 지원, 유진, 지수 등)은 중성으로 분류해 양쪽에 모두 나옵니다.

## 5. 한계와 주의

- **실제 인스타그램에서 사용 가능한 ID인지는 확인하지 않습니다.** 이 도구는 브라우저에 저장된 기록과의 중복만 거릅니다. 짧고 단순한 ID일수록 이미 쓰이고 있을 가능성이 높으니 가입 화면에서 직접 확인하세요.
- name과 ID가 항상 연관되지는 않습니다 (ID에 이름 흔적이 없는 방식도 있음).
- ID의 생년 숫자와 bio의 나이("22살")는 서로 맞추지 않습니다.
- bio 문구가 많이 반복될 수 있습니다 (정적 문구 50개 + 조합).
- 기록은 **브라우저별**입니다. 다른 브라우저나 기기에서는 중복 검사가 공유되지 않고, 브라우저 데이터를 지우면 기록도 사라집니다.
- 생성된 이름과 소개글은 가상의 값입니다. 실제 계정을 만들 때는 인스타그램의 이용 약관을 따르세요.

## 6. 자주 묻는 질문

**Q. 5,000개까지만 만들어져요.**
이전 버전을 열고 계신 겁니다. 20,000개 지원은 최신 `index.html`에서만 됩니다. 헤더 부제에
`Up to 20,000 per run`이 보이는지 확인하세요. 아래 [브랜치와 배포](docs/DEVELOPMENT.md#10-브랜치와-배포)도 참고하세요.

**Q. 저장 용량이 가득 찼다는 문구가 나와요.**
기록이 브라우저 저장 한도(약 5MB)를 넘으면 기록을 리셋하고 **최신 5,000개만** 남깁니다. 2만 개 기록이 약 0.9MB라서 보통은 발생하지 않습니다. 이 경우 이전 기록과의 중복 검사는 최신 5,000개 기준으로만 됩니다.

**Q. 2만 개를 만들면 얼마나 걸리나요?**
Node.js에서 측정하면 약 2~3초입니다. 브라우저에서는 500개마다 화면에 양보하므로 진행률이 갱신됩니다.

**Q. 이미 만든 ID를 다시 받고 싶어요.**
`Save All History`로 누적 기록 전체를 받을 수 있습니다. 화면을 새로고침하면 표는 비지만 기록은 남아 있습니다.

**Q. 기록을 처음부터 다시 쌓고 싶어요.**
`Reset Storage`를 누르세요. 누적 기록과 현재 표가 모두 비워집니다.
