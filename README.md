# 엘자매네 블로그 콘텐츠 파이프라인

> 네이버 상위 노출을 노릴 수 있는 퀄리티 높은 블로그 글을 **안정적으로** 생산하는 AI 자동화 시스템

---

## 개요

**엘자매네** (2020년생 첫째·2023년생 둘째 두 딸 육아 맘대디) 블로그 전용 콘텐츠 생산 파이프라인입니다.

대표(1인)는 **요청/승인만** 하고, AI가 역할을 분리해 단계별 산출물을 생성합니다.
출고 게이트 미충족 시 자동 반려·재작성하는 품질 보증 구조입니다.

---

## 사용 방법

1. **GitHub Pages URL** 접속 (배포 후 자동 생성)
2. 우측 상단 **[설정]** → Anthropic API 키 입력
3. **입력 폼** 작성 (메인 키워드 + 필수 포함 사항 필수)
4. **[파이프라인 시작]** 클릭

---

## 파이프라인 흐름

```
입력 → [스타일팩] → [SERP 분석] → [SEO 브리프] → [샘플 ← 대표 승인]
                                                         ↓
                                          [중복 검사] → [최종 출고 ← 게이트 자동 체크]
```

### 7단계 파이프라인

| 단계 | 파일 | 역할 | 담당 |
|------|------|------|------|
| 1 | `00_stylepack.md` | 스타일 규칙 + 코퍼스 레퍼런스 + 생활 디테일 | stylepack_generator |
| 2 | `01_serp_top5.md` | 네이버 상위 5개 콘텐츠 분석 | serp_analyst |
| 3 | `02_seo_brief.md` | 검색의도·키워드맵·목차·FAQ·CTA | seo_lead |
| 4 | `08_samples.md`  | 샘플 4문단 → **대표 승인** | writer |
| 5 | `09_dupe_report.md` | 4어절 이상 동일 구간 전수 검사 | dupe_scanner |
| 6 | `10_final.md`    | 최종 출고 본문 | writer |

---

## 출고 게이트 (자동 반려 규칙)

아래 중 하나라도 미충족이면 **자동 반려 후 재작성** (최대 3회):

- ✅ 첫 문장: `"샬롬! 행복한 엘자매네입니다."` 형식
- ✅ 페르소나: 첫째(2020년생) / 둘째(2023년생) 자연 언급 1회 이상
- ✅ 톤: 과장·광고 표현 없음 ("최고", "무조건 추천" 등 금지)
- ✅ 유사문서: `dupe_report` PASS 확인
- ✅ 분량: 800자 이상 + H2 소제목 구조

## 역할 분리

| 역할 | 책임 | 본문 작성 |
|------|------|-----------|
| 총괄(Chief) | 요청 티켓화, 단계별 호출, 최종 승인 요청 | ❌ |
| blog_lead   | 프로세스 진행/반려/체크리스트 관리 | ❌ |
| serp_analyst | 네이버 TOP5 분석 | ❌ |
| seo_lead | 키워드/구조/FAQ/내부링크 설계 | ❌ |
| **writer** | **최종 본문 작성/수정 전담** | ✅ |
| tone_editor | 톤/리듬/공감 흐름 점검, 수정 지시 | ❌ |
| dupe_scanner | 4어절 이상 동일 구간 리포트 | ❌ |
| rewrite_director | 서사/구조/문장 골격 재작성 지시 | ❌ |

## 기술 스택

- **Frontend**: 순수 HTML/CSS/JavaScript (프레임워크 없음)
- **AI**: Anthropic Claude API (claude-sonnet-4-6 기본)
- **Markdown 렌더링**: [marked.js](https://marked.js.org/)
- **호스팅**: GitHub Pages
